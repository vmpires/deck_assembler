# Player profile

Treat this as fact unless the current pitch overrides it.

## Formats

- Commander EDH: default **high Bracket 3 / low Bracket 4** — competitive upgraded lists, not casual mid power. Build for speed, interaction density, and a real win. Cap at **3 Game Changers** so the deck can still sit at Bracket 3 tables; go to **Bracket 4 (Optimized)** (more GCs, faster goldfish) when the pitch is tuned / high / competitive. Never propose Bracket 5 / cEDH.
- 60-card Pauper (paper / MTGO). Not Pauper Commander (PDH).

## How to build

- **Synergy first.** The deck needs a clear game plan and a supporting engine.
- **Then proven staples that serve that plan.** Do not add goodstuff that does not. Do not be cute for uniqueness.
- No collection inventory. No hard budget. Still **flag expensive cards** (roughly $20+ or obvious chase pieces). Do not assume proxies.

## Default tastes (welcome)

Combat and attack-trigger value, tokens, tribal/typal, spellslinger, control / interaction-heavy, lands-matter / ramp / big mana, incremental value engines, and combo that supports the plan (2–3 card engines; not infinite-or-bust unless the user opted into combo).

## Hard nos

- Stax, prison, hard locks, mass land denial, extra-turn chains.
- Chaos, randomizers, and group hug that does not win.

## Not defaults

Graveyard strategies (reanimator, aristocrats, self-mill) and politics / group-hug table dynamics. Use them only when the pitch is about them.

## Commander power

- Default (high B3 / low B4): at most 3 Game Changers; no MLD; no extra-turn chains; two-card infinites only if they are late-game and the user opted into combo. Prefer efficient tutors, premium interaction, and a plan that wins the table — not a pile of vanilla creatures.
- Bracket 4: faster and more efficient, still not a cEDH metagame deck. Name Game Changers explicitly. Use this when the user wants a fully competitive optimized list.
- Always state the intended bracket on the shortlist and the final list.
